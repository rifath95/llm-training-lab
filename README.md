# LLM Training Lab

The goal is to understand [Karpathy's nanochat](https://github.com/karpathy/nanochat) and the complete pipeline for training a conversational LLM from scratch.

So far, we've built a [transformer from scratch](https://github.com/rifath95/transformer-from-scratch). The [nanochat guide](nanochat-guide/00-NANOCHAT_LEARNING_ROADMAP.md) contains notes on the concepts and implementation. We'll work through them and build toward reproducing the pipeline.
